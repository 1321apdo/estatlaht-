# تطبيق استطلاع الرأي وسحب بطاقات فيزا المعتمد 💳📊

تطبيق أندرويد متكامل مبني باستخدام **Kotlin** و **Jetpack Compose** بنمط التصميم العصري **Material Design 3**. يتيح التطبيق للمستخدمين الإجابة على استطلاعات رأي تفاعلية، ربح النقاط اليومية، وتوليد وسحب بطاقات فيزا افتراضية مع تأكيد أمني وحفظ كامل للبيانات محلياً عبر قاعدة بيانات **Room**.

---

## 🌟 المميزات الرئيسية

- **📊 استطلاعات رأي تفاعلية ومتجددة**:
  - تصنيفات متعددة: التكنولوجيا، التجارة الإلكترونية، الألعاب، ونمط الحياة.
  - مكافآت فورية بالنقاط مع تحديث لحظي للرصيد.
  
- **💳 نظام بطاقات فيزا وسحب الأرباح**:
  - سحب أرصدة تبدأ من 5$، 10$، 25$ وصولاً إلى 50$.
  - توليد تفاصيل البطاقة الافتراضية محلياً (رقم البطاقة المكون من 16 رقماً، تاريخ الانتهاء، ورمز CVV).
  - سجل كامل لمعاملات السحب وبطاقات فيزا المفعلة.

- **🎁 مكافآت وأنشطة تفاعلية إضافية**:
  - تسجيل الدخول اليومي (Daily Check-in) لزيادة النقاط المستمرة.
  - استطلاع اليوم السريع بنقرة واحدة.
  - عجلة الحظ الدائرية لكسب نقاط عشوائية يومياً.

- **🛡️ أمان وإعلانات Google AdMob الرسمية**:
  - معرّف تطبيق أدموب الموثق: `ca-app-pub-8214981197698574~7842643561`.
  - معرّف وحدة البانر الإعلانية: `ca-app-pub-8214981197698574/4237977455`.
  - معرّف الناشر: `ca-pub-8214981197698574`.
  - دعم المعالجة البرمجية `LAYER_TYPE_SOFTWARE` لتفادي أخطاء الرسوميات على الأجهزة الافتراضية.

- **💾 قاعدة بيانات داخلية موثوقة**:
  - إدارة كاملة للمستخدم، الرصيد، المعاملات، والاستطلاعات المكتملة عبر **Android Room Database**.
  - دعم العمل بدون اتصال بالإنترنت وحفظ التقدم تلقائياً.

## 🚀 كيفية بناء وتشغيل التطبيق من سطر الأوامر

1. **استنساخ المستودع (Clone)**:
   ```bash
   git clone https://github.com/1321apdc/estlatht-.git
   cd estlatht-
   ```

2. **بناء نسخة الـ APK للاختبار (Debug APK)**:
   ```bash
   gradle assembleDebug
   ```
   *سيكون الملف جاهزاً في المسار:*  
   `app/build/outputs/apk/debug/app-debug.apk`

3. **تثبيت التطبيق على الهاتف المتصل عبر ADB**:
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```
